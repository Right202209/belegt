## 3. 一致性约定

- 核心对象：`DataPoint`、`Request`、`Question`、`Mapping`、`Evidence`、`Calculation`、`Answer`、`Approval`、`Conflict`、`SupplierRequest`、`ClosedQuestion`（详见 03）。
- 硬规则 R-NUM：数字答案必须引用 `Evidence` 或 `Calculation`，LLM 不生成数字（FR-401）。
- 新增 FR 按文档号段分配：04 → FR-006…009，07 → FR-010…019，11 → FR-020…024，01 → FR-104…107 / FR-504…507，05 → FR-206…209，08 → FR-304…309，13 → FR-405，06 → FR-406…409；10 → NFR-07 起。
- 法规日期以 13 为准：CBAM 50 t 门槛自 2026-01-01；证书销售 2027-02-01；首次年度申报与清缴 2027-09-30；EUDR 2026-12-30 / 2027-06-30；VSME 价值链上限自 2027-01-01 财年；电池护照 2027-02-18。
